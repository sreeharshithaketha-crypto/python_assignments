# Matplotlib Exercises

These beginner-friendly files answer the Matplotlib and histogram exercises
from the class notes. Each exercise has its question and answer in comments.

## Run the exercises

From the repository folder, run a file like this in PowerShell:

```powershell
python mathplotlib/matplotlib_exercise_01_line_chart.py
```

Install the libraries first if they are not already installed:

```powershell
python -m pip install matplotlib pandas
```

The Pandas CSV exercise reads `sales_data.csv` from the repository folder.
It uses the sales and orders from the class example and small sample customer
counts so it can show three number columns.
