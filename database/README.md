## Recommended run order

1. Run `basic_database_queries.py` first to create the `college_db` database and `students` table.
2. Then run the other files one by one as needed.
3. If you want the menu-based practice file, run `menu_driven_database_app.py` after the basics.

## Important

1. Make sure MySQL is installed and running on your system.
2. Update the username and password in the connection code if needed.
3. Some files assume the `college_db` database already exists.
4. If you run the insert examples repeatedly, duplicate key errors may appear depending on your existing table data.

## MySQL connection settings used

- Host: localhost
- User: root
- Password: empty string

If your MySQL password is different, change it in each file.
