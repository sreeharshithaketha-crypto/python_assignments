# Pandas and Model Examples

These are small practice files with sample data included in the code.

## Run the Pandas examples

From this folder, install the packages and run:

```powershell
python -m pip install -r requirements.txt
python emp.py
python datasets.py
```

- `emp.py` teaches DataFrames, filtering, `isin`, sorting, new columns, `groupby`, counts, missing values, duplicates, `loc`, and `iloc`.
- `datasets.py` practices IPL, weather, bank, and shopping questions.
- `models.py` contains Student, Employee, Product, and Course models. It is Django app code, so copy it into a Django app; it is not a standalone script.

All names and records in the sample tables are made-up practice data.
